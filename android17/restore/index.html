Restore original system

This page is prepared for a future tested recovery path back to the manufacturer firmware. No generic flashing commands are published yet.

Important: Restoring stock firmware can erase all data. Manufacturer security state may not necessarily return to its original condition after a custom system has been installed.
1. Identify the exact device
The precise model and region/build must match the official firmware used for recovery.
2. Back up everything
Photos, documents, authenticator data and anything else important must be copied somewhere safe first.
3. Obtain official firmware
Only an official firmware package intended for the exact verified model should be used.
4. Follow the device-specific recovery guide
Exact recovery instructions will only be added after the target device has been verified and the process has been tested.
