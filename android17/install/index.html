Installation guide

This page is prepared for the future release. There is no downloadable Android image yet, and these steps are intentionally incomplete until device compatibility is verified.

Important: Installing a custom Android system can erase all device data and may affect manufacturer security features. Do not flash anything until the exact device is confirmed as compatible and its bootloader can be officially unlocked.
1. Check compatibility
The exact phone model, architecture, partition layout, Treble support and bootloader state must be verified first.
2. Back up your data
A full backup is required before any real installation attempt. The release page will later list what is erased.
3. Download the release
Not available yet. When a tested build exists, the download button and SHA-256 checksum will appear automatically.
4. Install
Exact installation commands will only be published for hardware we have verified. No generic flashing instructions are provided yet.
