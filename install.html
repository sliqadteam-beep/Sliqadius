Sliqadius installieren

Hier findest du die kurzen Schritte für Windows, Android, macOS und die Browser-Version. Für die Browser-Version brauchst du keine klassische Installation.

Windows

Windows 10 / 11
1Lade Sliqadius.exe über den Windows-Download herunter.
2Öffne die heruntergeladene Datei. Wenn Windows einen Hinweis zeigt, prüfe Dateiname und Quelle und fahre nur fort, wenn du den Download von dieser Sliqadius-Seite gestartet hast.
3Beim ersten Start trägst du deinen Groq API-Key ein. Danach kannst du direkt chatten.
Windows herunterladen

Android

Google Play oder APK
1Am einfachsten installierst du Sliqadius über Google Play, sobald die Store-Version verfügbar ist.
2Alternativ kannst du die APK direkt laden. Android kann dafür einmalig die Erlaubnis für Installationen aus deinem Browser verlangen.
3Öffne Sliqadius und speichere deinen Groq API-Key in der App.
Google PlayAPK herunterladen

macOS

Apple Silicon + Intel
1Lade das macOS-Paket herunter und entpacke die ZIP-Datei.
2Öffne die passende Sliqadius-App für deinen Mac. Falls macOS die App beim ersten Start blockiert, nutze die Systemfreigabe für die bewusst heruntergeladene App.
3Trage beim ersten Start deinen Groq API-Key ein.
macOS herunterladen

Browser

PC, Mac, Android, iPhone und iPad
1Öffne die Browser-Version von Sliqadius.
2Trage einmal deinen Groq API-Key ein. Sliqadius merkt ihn sich danach in diesem Browser auf diesem Gerät.
3Optional kannst du im Browser-Menü „Installieren“, „Zum Startbildschirm hinzufügen“ oder eine ähnliche Option wählen. Die genaue Bezeichnung hängt vom Browser ab.
Browser-Version öffnen
API-Key: Sliqadius benötigt für die KI-Funktionen einen eigenen Groq API-Key. Verwende deinen privaten Key nicht auf fremden oder gemeinsam genutzten Geräten.
