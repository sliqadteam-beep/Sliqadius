# Sand:Box Android

Android Studio source for the Sliqado Sand:Box game.

## Build an APK
1. Open the `sandbox-android` folder in Android Studio.
2. Wait for Gradle sync to finish.
3. Use **Build > Build App Bundle(s) / APK(s) > Build APK(s)**.
4. The debug APK is normally created at `app/build/outputs/apk/debug/app-debug.apk`.

The app loads the current game from `https://sliqado.org/sandbox/`, so website updates also appear in the Android app.
