Datenschutzerklärung

Stand: 19. August 2026

1. Überblick

Sliqadius ist ein KI-Assistent. Die Browser-Version wird als statische Website bereitgestellt. Chats, Einstellungen und der Groq API-Key werden lokal im Browser des Nutzers gespeichert.

2. Lokale Speicherung

Die Browser-Version kann Chats, Entwürfe, Sprache, Modus, Einstellungen und den Groq API-Key in LocalStorage und/oder IndexedDB speichern. Diese Daten bleiben auf dem jeweiligen Gerät, bis sie vom Nutzer oder Browser gelöscht werden.

3. KI-Anfragen an Groq

Wenn eine Nachricht oder ein Bild an Sliqadius gesendet wird, werden die für die Antwort notwendigen Inhalte direkt vom Browser an die Groq API übertragen. Dazu gehören die Nachricht, ein begrenzter Chat-Kontext, gegebenenfalls ein hochgeladenes Bild und der vom Nutzer bereitgestellte API-Key zur Authentifizierung. Für die Verarbeitung durch Groq gelten zusätzlich die Bedingungen und Datenschutzregeln von Groq.

4. API-Key

Der Groq API-Key ist ein privater Zugangsschlüssel des Nutzers und wird lokal im Browser gespeichert. Auf gemeinsam genutzten Geräten sollte kein privater API-Key gespeichert werden.

5. Bilder

Bilder werden vor dem Senden verkleinert bzw. komprimiert. Für die KI-Analyse wird eine Bildversion an Groq übertragen. Eine kleinere Vorschau kann zusammen mit dem Chat lokal gespeichert werden.

6. Drittanbieter

  • GitHub Pages für das Hosting der Website.
  • Groq für KI-Anfragen.

7. Löschen von Daten

Lokale Sliqadius-Daten können durch Löschen der Website-Daten im Browser oder über die Funktionen der Browser-Version entfernt werden.

8. Kontakt

Fragen zu Sliqadius können über das öffentliche GitHub-Repository gestellt werden: sliqadteam-beep/Sliqadius.

Privacy Policy

Sliqadius Web stores chats, drafts, language, mode, settings and the user's Groq API key locally in the browser. AI requests are sent directly to Groq with the content required to generate a response. Users can remove local browser data at any time.
