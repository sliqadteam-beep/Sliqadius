Datenschutzerklärung

Stand: 19. August 2026

1. Überblick

Sliqadius ist ein KI-Assistent. Die Browser-Version wird als statische Website bereitgestellt. Chats, lokale Memories, Feedback, Einstellungen, Nutzungsstatistiken und der Groq API-Key werden grundsätzlich lokal im Browser des Nutzers gespeichert.

2. Lokale Speicherung

Die Browser-Version kann Chats, Anhänge bzw. lokale Vorschauen und extrahierte Dateiinhalte, Memories, Feedback, Sprache, Modus, Darstellung, Nutzungsstatistiken und den Groq API-Key in LocalStorage und/oder IndexedDB speichern. Chat-Bibliotheken werden lokal dem jeweils verwendeten API-Key zugeordnet. Diese Daten bleiben auf dem jeweiligen Gerät, bis sie vom Nutzer oder Browser gelöscht werden.

3. KI-Anfragen an Groq

Wenn eine Nachricht, ein Bild oder eine unterstützte Datei an Sliqadius gesendet wird, werden die für die Antwort notwendigen Inhalte direkt vom Browser an die Groq API übertragen. Dazu gehören die Nachricht, ein begrenzter Chat-Kontext, ausdrücklich gespeicherte Memories und gegebenenfalls Bilder oder aus Dateien extrahierter Text sowie der vom Nutzer bereitgestellte API-Key zur Authentifizierung. Für die Verarbeitung durch Groq gelten zusätzlich die Bedingungen und Datenschutzregeln von Groq.

4. API-Key

Der Groq API-Key ist ein privater Zugangsschlüssel des Nutzers und wird lokal im Browser gespeichert. Sliqadius nutzt ihn außerdem lokal zur Trennung der zugehörigen Chat-Bibliotheken. Der Key wird nicht auf einem eigenen Sliqadius-Server gespeichert. Auf gemeinsam genutzten Geräten sollte kein privater API-Key gespeichert werden.

5. Bilder, PDFs und Dateien

Bilder werden vor dem Senden verkleinert bzw. komprimiert. Für die KI-Analyse wird eine Bildversion an Groq übertragen. Eine kleinere Vorschau kann zusammen mit dem Chat lokal gespeichert werden. Bei unterstützten Text- und Code-Dateien wird Text lokal im Browser gelesen. Bei PDFs wird Text im Browser extrahiert. Der für die Anfrage benötigte Dateitext kann anschließend zusammen mit der Nachricht an Groq übertragen werden.

6. Spracheingabe und Vorlesen

Die optionale Spracheingabe verwendet die Spracherkennungsfunktion des verwendeten Browsers. Je nach Browser und Betriebssystem kann die Verarbeitung der Sprache durch den Browser-, Betriebssystem- oder Spracherkennungsanbieter erfolgen. Das Vorlesen von Antworten verwendet die Sprachsynthese des Browsers bzw. Betriebssystems. Sliqadius betreibt dafür keinen eigenen Sprachserver.

7. Installierbare Web-App

Wenn Sliqadius als Web-App installiert wird, kann ein Service Worker statische App-Dateien wie HTML, JavaScript, Icons und Übersetzungen im Browser-Cache speichern, damit die Oberfläche zuverlässiger geladen werden kann. KI-Anfragen benötigen weiterhin eine Internetverbindung zu Groq.

8. Drittanbieter

  • GitHub Pages für das Hosting der Website.
  • Groq für KI-Anfragen.
  • jsDelivr / PDF.js zum Laden der PDF-Auslesefunktion, wenn eine PDF verwendet wird.
  • Browser- bzw. Betriebssystemdienste für optionale Spracheingabe und Sprachausgabe.

9. Löschen und Sichern von Daten

Lokale Sliqadius-Daten können durch die Funktionen der Browser-Version, durch eine neue lokale Bibliothek oder durch Löschen der Website-Daten im Browser entfernt werden. Über die Sicherungsfunktion kann der Nutzer seine Sliqadius-Daten als JSON-Datei exportieren und später wieder importieren.

10. Kontakt

Fragen zu Sliqadius können über das öffentliche GitHub-Repository gestellt werden: sliqadteam-beep/Sliqadius.

Privacy Policy

Sliqadius Web stores chats, local memories, feedback, settings, usage statistics and the user's Groq API key locally in the browser. Supported files are read in the browser and content required for an AI answer can be sent directly to Groq. Image previews and extracted file text can be stored locally with chats. Optional speech input and text-to-speech use browser or operating-system capabilities, which may involve their respective providers. The installable web app may cache static application files with a service worker. Users can export backups and remove local browser data at any time.
