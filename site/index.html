Questions

Good to know.

Does SliqServer permanently turn my device into a server?

No. It is a normal app. When the Minecraft server is stopped, the device can be used normally.

Can Java and Bedrock players join the same server?

Yes when Bedrock support is enabled. SliqServer uses the Geyser/Floodgate bridge for Bedrock access to the Java server.

Does a custom domain automatically make my home server public?

No. DNS only points a name at an address. Public access still needs correct router port forwarding or a compatible tunnel setup.

Can I use plugins and mods at the same time?

Paper is designed for plugins, while Fabric is designed for mods. Choose the server software that matches what you want to install.
