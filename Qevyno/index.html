How it works

From install to chat in a few steps.

Qevyno keeps registration and login in one simple phone-first flow.

Passwords are stored by the Qevyno server as password hashes, not plain-text passwords. Messages are transported over HTTPS. Qevyno is not currently end-to-end encrypted.
1
Install Qevyno

Download the APK and install it on Android 8.0 or newer.

2
Enter your number

The country code is chosen from the device or mobile-network region and can be changed manually.

3
Continue automatically

Existing accounts go to password login. New numbers continue to name and password creation.

4
Start a chat

Enter another Qevyno user's exact phone number and send a message.
