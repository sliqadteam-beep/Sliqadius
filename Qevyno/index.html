How it works

Three steps. That’s it.

Install the APK, create your account, and start a conversation using another user’s exact phone number.

01 — INSTALL

Download the APK

Tap the download button and install Qevyno on an Android 8.0 or newer device.

02 — CREATE

Make your account

Choose a display name and register with an international phone number and password.

03 — CHAT

Find someone

Enter their exact phone number, open the chat and send your first message.

Official Qevyno server
https://qevyno.sliqado.org
The Android app uses this endpoint automatically. Your dedicated tablet hosts the Qevyno backend and Cloudflare Tunnel provides the public HTTPS route.
Server configured
Important: Phone numbers are currently account identifiers only. SMS ownership verification is not enabled yet. Qevyno currently uses HTTPS for transport, but messages are not end-to-end encrypted.
