# Sliqadius Android

Android-Version von Sliqadius für die spätere Veröffentlichung bei Google Play.

## Geplantes Design
- Dunkles Design, ähnlich der Windows-App
- Grüner Sliqadius-Akzent
- KI-Chat
- Bildanalyse
- Websuche
- API-Key-Einstellungen
- 14.999 Nachrichten täglich als Anzeige
- Keine Bildgenerierung

Die Android-App wird separat von der bestehenden Windows-App entwickelt.
